## mod介绍
游玩了老国产rpg回合制游戏后，一天主包突然看到了游戏弈仙牌，被游戏简明的设计和深度的策略性深深震撼，从那之后，主包诞生制作卡牌游戏的想法。后来游玩了杀戮尖塔，逐渐理解了卡牌游戏的本质：代价->效果。于是，一个想法突然出现，如果一个游戏的卡牌将代价和效果分开抽取，再进行组合，这样不是极大的丰富了构筑，同时还方便设计。
于是本mod出现了，这是一个基于杀戮尖塔原版系统的实验。玩家在战斗中得到的奖励不再是一张张卡片，而是卡片的碎片，一个部分负责费用，一个部分负责效果。在这里，玩家可以在一个二费牌的壳子上，拼凑上两张能够形成配合的1费牌，可以把高费牌和加费绑定在一起避免鬼抽（比如2费牌和0费的加费牌拼接到同一个2费牌的底座上）。
拼接卡牌还相当于删牌，所以对应的我有所削弱，给卡牌的拼接增加了条件，给高费的卡牌增加了减益，另外，由于卡牌需要拼接，那么抓牌的难度增大了，比如你遇到一张很想抓的2费效果，但是抽出来的3个费用都是1费的，那么就没办法带着那张2费效果牌。反过来，你可能需要抓一张空白的费用牌（比如3费，没有任何效果，相当于伤口）来为接下来听牌做准备。
